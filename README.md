> Версия: **0.0.1**

# AlchemyHelper

Помощник для события «Алхимия» в GTA5RP.

## Возможности

- Поиск кратчайшего пути синтеза элемента.
- Работа с текущим **Шкафом реактивов**.
- Постоянный **Атлас 720** с сохранением прогресса.
- Полный путь элемента от четырёх базовых элементов: Вода, Пламя, Земля, Воздух.
- Таймер 10-минутной сессии.
- Русские названия элементов.

## Файлы

- `alchemy_helper.py` — основная программа.
- `alchemy.json` — 720 элементов и рецепты.
- `translations.json` — русские названия.
- `alchemy_helper.spec` — конфигурация PyInstaller.
- `VERSION` — текущая версия проекта.

## Запуск

```text
python alchemy_helper.py
```

## Сборка EXE в Windows

```text
py -m pip install pyinstaller
pyinstaller --clean --noconfirm alchemy_helper.spec
```

Готовый файл появится в `dist\AlchemyHelper.exe`.

## Прогресс

Программа автоматически создаёт `progress.json` рядом с собой. В нём хранится прогресс Атласа между запусками. Этот файл не должен попадать в Git.
